# Architecture Decision Records (ADR)

An append-only log of significant technical and architectural choices.

| Date | Title | Decision | Reason & Consequences |
| :--- | :--- | :--- | :--- |
| 2026-11-03 | Adopt GrooveSkills Harness | Initialized `.grooveskills/` control plane with ODD | Clean, encapsulated agent memory, 3-lane ODD flow, and English copy standard |
| 2026-11-03 | Universal Defensive Typing for Registry | Use `globalThis` defensive access in templates | Prevents TS2580 errors in minimal consumers (Workers, Vite) lacking `@types/node` |
| 2026-11-03 | Synthetic Registry Typecheck | Verify templates against minimal tsconfig | Ensures registry templates remain zero-dependency and universally safe |
| 2026-11-03 | English-Only Communication Standard | CLI prompts, logs, and docs strictly in English | Maintains international OSS consistency and alignment with `@3lineas` standard |
| 2026-11-17 | Migrate to Installable NPM Package (v1.0.0) | Subpath Exports + `sideEffects: false` + optional `peerDependenciesMeta` (`hono`, `sonner`) | Eliminates copy-paste CLI overhead while preserving tree-shaking and optional peer dependencies |
| 2026-11-17 | English-First Default Messages with 5-Locale Dictionary | Default `"en"` fallback strings with `"en" \| "es" \| "pt" \| "it" \| "fr"` dictionary resolved via per-call `locale`, `setGroovepackLocale()`, or env vars (`GROOVEPACK_LOCALE` / framework-prefixed equivalents) | Aligns default copy with `AGENTS.md` while supporting multi-language consumers without bundle bloat |
| 2026-11-17 | Retain Full Skill Set & Native node:test Runner | Keep all GrooveSkills installed for future package libraries and keep `tsx --test` as the minimal package test runner | Preserves architectural guidance for upcoming modules with ~180ms zero-bloat test execution |
| 2026-11-17 | Shadcn v4 (`@base-ui/react/toast`), Vinext Static `import.meta.env`, & Hono RPC Constraint | Replace `sonner` with `@base-ui/react/toast` (throwing an explicit error if missing), use static `import.meta.env` access for Vinext `ModuleRunner`, and isolate `AnyHonoApp` for `createHonoClient` | Aligns `@3lineas/groovepack` with Shadcn v4 Base UI, Vite 8 / Vinext Workers runtime, and Hono routers with custom `Bindings`/`Variables` |
| 2026-11-18 | Zero-Arg `toast` & `locale` + `@3lineas/groovepack/vite` | Removed `toast` and `locale` arguments from `apiToast`/`createApiToast`/`apiAction` and removed `setGroovepackLocale()`. Locale is 100% env-driven (`GROOVEPACK_LOCALE` / `NEXT_PUBLIC_GROOVEPACK_LOCALE`). `resolveToastManager()` auto-loads `${GROOVEPACK_SHADCN_PATH ?? "/src/components/ui"}/toast`, with optional `groovepack()` Vite plugin for static bundling | Keeps call sites ultra-clean (`apiToast({ action, onSuccess })`) without passing repetitive `toast` or `locale` parameters |
| 2026-11-18 | Bundler-Safe `cloudflare:workers` Service Binding & `getHeaders` | Use non-literal dynamic import (`["cloudflare", "workers"].join(":")`) with `@vite-ignore` and `webpackIgnore: true` in `resolveServiceBinding`, plus `fallbackBaseUrl + pathname + search` rewrite in `dispatchRequest` | Enables native Cloudflare Service Bindings in `createApiClient`/`createHonoClient` without breaking Vite/Next.js/Node builds or using `eval` |
